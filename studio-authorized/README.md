# 摄影定调工作台

电脑与手机浏览器共用的摄影局部编辑工作台。可添加到手机主屏幕。

功能：地毯替换；上衣、下装、全身换装与版型选择；软装替换；多款天花板；孔洞、电线、地板污物等瑕疵修补；多款窗外景与景深；多款窗帘与颜色。支持每项参考图和提示词、整体补充词，以及 1 / 3 / 5 个方案。

每项操作拥有独立画笔和矩形选区。产品保护区优先；使用 PNG 蒙版调用 Images edits，之后仅将选中像素合成回原图。未选中区域和完全保护区域保留解码后的原图像素。输出 PNG 尺寸与原图一致。选区内生成的质感、光线与边缘仍需人工检查。

项目手动保存到当前设备 IndexedDB，可导出、导入 JSON；没有自动跨设备同步。生成期间应保持网页打开。原图和参考图在出图时发送至 OpenAI，服务不另外存储图片。本站保留 Sites 私有访问与 ChatGPT 登录。

## Runtime

在 Sites 配置服务器密钥 `OPENAI_API_KEY`。密钥不得进入前端或 Git。API 图像调用按账户用量计费。

## Verification

- `node node_modules/typescript/bin/tsc --noEmit`
- `node --experimental-strip-types tests/image-preservation.mjs`
- Sites build helper

首次实际 API 编辑请求返回 HTTP 429、`credit_balance_exhausted`，账户余额不足。补足账户余额后才可验证生成结果；未因测试失败更换模型或密钥。


## Gmail 授权与后台管理

`OWNER_EMAIL` 是部署时固定的唯一管理员邮箱，由 Sites 已验证登录邮箱匹配。所有工具页、状态、心跳和出图 API 均使用服务端白名单，后台 API 额外验证管理员身份。普通用户不能自授权限；未批准、暂停和撤销用户无法调用出图。白名单要求精确 Gmail 邮箱，不合并未批准的别名。

D1 持久化成员授权、活动心跳、任务记录、每天调用额度与管理操作审计。后台每 5 秒刷新，在线定义为近 90 秒心跳。额度按北京时间每天重置，通过单条 SQLite upsert 原子保留，重复任务编号拒绝提交。生成请求不等于最终下载次数或 API 账单；后台不保存原图、参考图和生成图。

部署保留现有的仅所有者 Sites 入口。要让其他 Gmail 用户到达邮箱验证页，需要先由所有者确认开启可访问的登录入口，然后设置 `EXTERNAL_LOGIN_ENABLED=true` 并调整 Sites 入口访问。入口公开不授权工作台：所有内容及接口仍由已验证身份和服务器白名单保护。

检查新增权限规则与数据库查询：

- `node --experimental-strip-types tests/access-control.mjs`
- `python tests/quota-migration.py`

未使用 Gmail 邮件权限或读取邮箱；用户通过绑定相同 Gmail 地址的 ChatGPT 账户登录。


## 当前桌面售卖版 V1

新增 /admin/licenses：收款后人工签发绑定 Gmail 的长期 V1 激活码，停用/恢复授权、查看与退出设备。新增 /desktop 供系统浏览器确认桌面登录。每账号最多两台同时在线，云端原子分配，25 秒心跳、90 秒名额过期。桌面登录凭证 30 天后需重新登录，软件授权不按月到期。

桌面软件位于 desktop/。客户 API 密钥只在桌面主进程使用并通过系统安全存储加密；出图直接请求客户 API，绝不回退到管理员密钥。网页版普通客户不能调用管理员出图 API；管理员本人保留原有网页功能。Plus 用户可导出材料、手动在 ChatGPT 出图并导回选区合成。

Windows 安装包为 x64、未签名，需完成 Windows 实机验收后正式售卖。付款登记为人工流程，未实现自动支付、自动更新、跨设备项目同步。桌面任务仅由客户端报告元数据，不用于核算真实 API 账单。源码和凭证不包含任何客户真实数据。
