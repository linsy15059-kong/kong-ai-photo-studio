# 摄影定调工作台 · Windows 售卖版 V1

本目录是桌面客户端源码与 Windows 打包工程。一次性软件授权，客户使用自己的 OpenAI API，或使用 ChatGPT 手动辅助流程。

## 当前交付状态

云端授权接口、激活确认页和管理员授权中心已经实现。桌面前端已构建，API 路由与并发设备限制通过自动测试。
Windows x64 安装包已通过跨平台打包流程生成。当前环境没有 Windows 桌面，安装、浏览器登录、本机凭证保存和真实出图尚未进行 Windows 实机验收；请先测试再正式售卖。

## 在 Windows 生成安装包

1. 安装 Node.js 22.13 或更高版本，确保可访问 npm 与 Electron 官方下载源。
2. 解压完整包，进入 desktop 文件夹，双击 Build-Windows.cmd。
3. 脚本安装 Electron 与 electron-builder，执行客户 API 隔离测试，然后生成 release/PhotographyToneStudio-Setup-1.0.0-x64.exe。
4. 安装包生成后，应在 Windows 10/11 64 位电脑验收登录、激活、API 本地加密、上传、选区、出图、导出、手动辅助、两台同时使用和第三台被阻挡，再发给付费客户。

前端与规则文件已随交付包预编译，无需客户安装 Node.js。只有制作安装包的人需要 Node.js；最终客户只安装打包后的 EXE。
本次安装包未使用发布者代码签名证书，Windows 可能显示未知发布者提示。若正式售卖，发布者可配置自己的代码签名证书。

## 管理员操作

- 使用管理员账号访问 https://photography-tone-studio.linsy15059.chatgpt.site/admin/licenses 。
- 在实际收款后填写客户 Gmail 和订单备注，签发 V1 长期授权。
- 激活码只在签发时显示，复制交付给客户；未激活且遗失时可重新签发。
- 后台每 5 秒刷新在线设备，支持停用、恢复、退出指定设备。
- 此版本人工登记付款，不内置支付渠道。V1 授权不按月到期；不代表免费提供未来大版本或无限期云服务。

## 客户流程

安装 → 点击激活/登录 → 系统浏览器验证购买邮箱对应的 ChatGPT 身份 → 首次填写激活码 → 回到软件。
两台设备可以同时在线。第三台不自动踢人，可退出已有设备后进入。电脑数量可以更换，不是永久只能绑定两台。
登录凭证有效 30 天，过期后再次登录；这不会使已购买的软件授权到期。
每 25 秒续期，在线名额 90 秒失效。正常退出立即尝试释放名额，断网和异常关闭最多等待 90 秒。

## 两种 AI 使用方式

**API 自动出图**：客户在 API 设置输入自己的 OpenAI 凭证，Windows DPAPI 加密保存到当前 Windows 用户的应用目录。桌面主进程直接调用 https://api.openai.com/v1/images/edits 。客户密钥、原图、参考图和返回图片不发送到软件授权后台。缺少凭证、授权无效、设备名额不足或 API 余额不足时不出图；绝不回退到卖家的凭证。每项修改各调用一次 API，1/3/5 个方案分别按实际次数计入客户账单。

**ChatGPT 手动辅助**：上传照片 → 对当前工具标记选区 → 导出原图、蒙版、参考图和提示词 → 自行上传到 ChatGPT 进行修改 → 导回同画幅结果图 → 软件仅合成导出时记录的选区。选区外保留原图像素，选区内效果仍需检查。多项修改逐项完成，不自动调用或消耗 Plus 订阅。

## 费用与记录

网页版客户出图接口已阻止使用管理员 API，管理员本人保留网页版原有出图功能。
桌面任务记录仅上报工具、状态和时间，不上传提示词、客户 API 密钥或图片。记录由客户端报告，仅供软件使用监控，不能作为服务商账单依据。API 返回成功不等于用户最终下载。
原图、项目与结果默认保存在当前客户端 IndexedDB，可导出、导入项目 JSON；没有跨设备项目同步。
如果生成过程中授权失效或网络中断，上游已经开始的请求可能仍产生费用；软件会停止后续请求。

## 开发

根目录安装网站依赖并构建网站后，运行 node desktop/build-frontend.mjs 更新桌面 frontend/ 与 rules.mjs；打包工程仅包含预构建资源和主进程文件，不包含云端源码、环境变量或管理员密钥。
桌面隔离测试：node --test desktop/tests/customer-api.mjs
真实 SQLite 并发与权限测试：python3 tests/desktop-devices.py
修改后的客户端仍需 Windows 实机验收。安装包更新分发、自动更新、在线支付、云项目同步未在本版本实现。
